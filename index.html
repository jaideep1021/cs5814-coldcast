Project overview

Make informed AI decisions before spending the cost of evaluation

Modern AI benchmarks usually explain how a model performed after thousands of questions have already been evaluated. In practice, teams often need a useful prediction before committing time, money, and computing resources.

ColdCast estimates the probability that an AI system will answer a new question correctly without allowing that system to attempt the question. It combines the meaning of the question, information about the AI system, evidence from similar tasks, and a small number of revealed labels.

The result is a calibrated reliability forecast that can support model routing, benchmark planning, human escalation, and safer AI deployment.

Primary output P(correct)

An honest probability rather than a simple yes or no prediction

Key data sources

Competition data used by ColdCast

The project uses the official Stanford AIMS Predictive AI Evaluation Competition release.

RM

AI response matrix

Observed correct and incorrect outcomes for pairs of AI systems and evaluation items.

SM

System metadata

Model, provider, harness version, reasoning effort, evaluation date, and configuration settings.

IT

Evaluation items

Question text, structured item features, and information about tools or interactors.

5L

Revealed labels

Five observed outcomes per test system for rapid capability adaptation.

Proposed approach

Four complementary signals create one reliability forecast

Each component answers a different question about whether an AI system is likely to succeed.

QT

Question representation

A pretrained text encoder captures the domain, reasoning type, complexity, and likely difficulty of each task.

AI

System representation

Learned embeddings represent the model, provider, reasoning effort, tools, and available configuration details.

RE

Retrieval evidence

Semantically related questions reveal how comparable AI systems performed on similar tasks.

5L

Rapid adaptation

Five revealed labels update a compact capability profile for a newly evaluated AI system.

Research hypothesis

The complete system will make more accurate and better calibrated predictions.

ColdCast will achieve a lower item held out Brier score than global accuracy, system history, metadata only, text only, retrieval only, and neural collaborative filtering baselines.
